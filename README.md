# נעילת אפליקציות — Android 4.4.4+

אפליקציית Android פשוטה לנעילת אפליקציות בעזרת PIN, ללא Accessibility Service.

## מה יש ב-V1
- PIN באורך 4–8 ספרות.
- מסך ניהול יישומים.
- שני מצבים: נעילה לפי רשימה, או נעילת הכול למעט רשימת החרגות נפרדת.
- שירות foreground שמנטר את האפליקציה שבחזית.
- פתיחה זמנית של יישום נעול לאחר PIN, עד שעוברים ממנו.
- הפעלה מחדש לאחר BOOT_COMPLETED.
- מסך אודות.
- אפשרות להפעיל Device Admin כדי להקשות על הסרה לא מכוונת.
- minSdk 19, כלומר Android 4.4 KitKat.

## מגבלת מערכת חשובה
ב-Android 4.4.4 אין API מודרני של UsageStats, ולכן המימוש משתמש ב-ActivityManager.getRunningTasks(). הוא מתאים ל-KitKat, אבל אינו יכול להבטיח נעילה חסינת-עקיפה מול root, Safe Mode, force-stop, הסרה של האפליקציה, או רכיבי מערכת/ROM שמגבילים ניטור משימות. לכן "100% בלתי ניתן לעקיפה" אינו אפשרי כאפליקציה רגילה ללא הרשאות מערכת/root.
